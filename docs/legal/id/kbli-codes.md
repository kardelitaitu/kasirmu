# KBLI Codes

> The five KBLI codes registered for the PT Perorangan, and the business activity each
> one legitimizes. Selection rationale: `[UNVERIFIED]` — codes were chosen to cover an
> existing software/hardware business, not derived from official KBLI guidance.

| Code | Name | Why it is included |
|------|------|--------------------|
| **62010** | Aktivitas Pemrograman Komputer | Core coding and API integration work (Midtrans / EDC) |
| **58290** | Penerbitan Perangkat Lunak Lainnya | Commercialization and licensing of the SaaS product |
| **63102** | Jasa Infrastruktur Komputasi & Hosting | Cloud merchant database and data synchronization |
| **46511** | Perdagangan Besar Komputer & Perlengkapan | Legal umbrella for **importing** EDC machines (B2B) |
| **47401** | Perdagangan Eceran Komputer & Perlengkapannya | Retail sale of cashier packages to UMKM |

## Points to confirm

- `[UNVERIFIED]` **46511 vs. import rights.** Holding a wholesale-trade KBLI is not by
  itself an import licence — verify what Bea Cukai actually requires, in relation to the
  API-U question in [`entity-setup.md`](./entity-setup.md#open-question-does-the-nib-also-function-as-api-u).
- `[UNVERIFIED]` **Coverage against the real product.** The five codes were not checked
  against what kasir.mu actually sells (SaaS subscription, hardware bundle, or both).
  If hardware is only ever drop-shipped, `46511`/`47401` may be unnecessary — and an
  unused trade KBLI is a recurring compliance surface, not a free option.
- `[UNVERIFIED]` **Risk level per code.** UMK licence handling depends on whether a code
  is classified low- or high-risk; nothing here records which of these are which.
