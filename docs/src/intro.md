# kasir.mu Documentation

Welcome to the kasir.mu documentation portal — a single place for hand-written
guides, architecture decision records, and API references for the Rust
workspace and the TypeScript frontend.

## What's here

| Category | Content |
|----------|---------|
| **Docs** | Hand-written guides from `docs/` and ADRs from `docs/decisions/` |
| **Rust** | API reference generated by `cargo doc` |
| **TypeScript** | API reference generated by TypeDoc from `ui/src` (api, types, hooks) |

## Building the portal

Run `scripts/build-docs.sh` (or `build-docs.ps1` on Windows). It generates the
API docs, copies the guides and ADRs into the book source, regenerates the
sidebar, and builds the portal into `docs/book/`. Then open
`docs/book/index.html`, or run `mdbook serve` inside `docs/` for a dev server
at `http://localhost:3000`.

> The Docs content is placeholder for now and will be rewritten later.
